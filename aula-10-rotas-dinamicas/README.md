# 🎮 Jogos API

> API REST desenvolvida com **NestJS + TypeScript** para gerenciamento de jogos.

---

## 📌 Sobre o projeto

Este projeto foi desenvolvido utilizando **NestJS**, seguindo uma estrutura modular e organizada.

Atualmente, o projeto possui o módulo responsável pelo gerenciamento de **jogos**, separando:

- 🎯 Controllers
- ⚙️ Services
- 🧪 Testes
- 📦 Módulos da aplicação

---

## 🛠️ Tecnologias

| Tecnologia | Utilização |
|---|---|
| 🟢 Node.js | Ambiente de execução |
| 🐈 NestJS | Framework backend |
| 🔷 TypeScript | Linguagem |
| 🧪 Jest | Testes automatizados |
| 📦 npm | Gerenciamento de pacotes |
